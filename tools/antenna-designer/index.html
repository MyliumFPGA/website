About This Tool

This tool generates Archimedean spiral antenna designs optimized for PCB fabrication using JLCPCB materials and capabilities. The design calculations account for substrate effects, dielectric constants, and manufacturing constraints.

Key Features:

  • Automatic wavelength and impedance calculations
  • Material property database for JLCPCB options
  • Manufacturing validation (minimum trace width/spacing)
  • KiCad PCB file export for direct fabrication
  • SVG export for documentation

Note: All processing happens in your browser. No data is sent to any server.
